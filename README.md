# Pour Arielle 💚

Site romantique bilingue (FR/EN), vert & rose. HTML/CSS/JS simple, sans installation.

## Personnaliser
Tout est dans `js/content.js` : date de début, photos, vidéos Snap, poèmes, raisons, lettre finale.
- Photos → dossier `photos/`
- Vidéos Snap (.mp4) → dossier `videos/`

## Voir le site
Ouvre `index.html` dans le navigateur (ou `python3 -m http.server`).
Pour le mettre en ligne gratuitement : GitHub Pages (Settings → Pages → branche → `/ (root)`).
